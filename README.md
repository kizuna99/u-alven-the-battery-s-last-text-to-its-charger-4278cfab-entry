Every morning the charger handed over a full 100%, and every day the battery cheerfully burned through it all — so when the end finally comes at the last percent, there is just enough charge left for one goodbye text, and it does not even survive to the end of its own sentence. This entry is the small Python program that delivers that message: running `main.py` validates the line against the contest gate (a single line of UTF-8 text, 1–200 characters) and writes it, with no trailing newline, to `/output/entry.txt`, then reads the file back to prove the bytes on disk are exactly the farewell it meant to send.
