A make.fun bounty entry: a small Python program (`main.py`) that writes the
phone battery's last text message to its charger — one line of plain text,
at most 200 characters — to `/output/entry.txt`.

The line:

> hey, don't cry for me. you gave me 100% every morning and I spent it all scrolling. if anyone asks, tell them I died doing what I loved: ignoring the low battery warning at 20, 15, 10, 5 and

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
